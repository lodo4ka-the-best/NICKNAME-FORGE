# NICKNAME FORGE

Генератор игровых никнеймов на основе реальных ников киберспортсменов.

## Что делает

1. **Генерирует** ники через Character N-gram Language Model, обученную на 500+ реальных никах
2. **Оценивает** каждый ник по 8 критериям (естественность, произносимость, баланс гласных, длина и т.д.)
3. **Проверяет** занятость через DuckDuckGo (универсальная проверка для любых игр)
4. **Показывает** результаты со статусом ✅ свободен / ❌ занят

## Использование

### Базовая генерация

```bash
python main.py --style epic --count 5
```

### С проверкой занятости

```bash
python main.py --style epic --count 5 --check
```

### Другие стили

```bash
python main.py --style dark --count 10
python main.py --style cyber --count 10 --check --game csgo
python main.py --style cute --count 10
python main.py --style mage --count 10
python main.py --style sniper --count 10
```

### Все параметры

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `--style` | Стиль: `epic`, `dark`, `cute`, `mage`, `cyber`, `sniper` | `epic` |
| `--count` | Сколько ников сгенерировать | `5` |
| `--platform` | Платформа: `default`, `xbox`, `psn`, `steam`, `minecraft`, `discord` | `default` |
| `--check` | Проверить занятость через DuckDuckGo | выключено |
| `--game` | Контекст поиска: `esports`, `dota`, `csgo`, `valorant`, `lol` | `esports` |
| `--min-len` | Минимальная длина ника | `4` |
| `--max-len` | Максимальная длина ника | `12` |
| `--threshold` | Порог качества (0-1). Чем выше — тем строже | `0.60` |
| `--seed` | Сид для воспроизводимости | `42` |

## Как это работает

### 1. Character N-gram Language Model

Модель учится на корпусе реальных ников киберспортсменов (`corpus/nicknames.py`).
Для каждого контекста (1-3 предыдущих буквы) запоминает распределение следующей буквы.
Генерация — семплинг из этого распределения.

### 2. Оценка по 8 критериям

| Критерий | Вес | Что оценивает |
|----------|-----|---------------|
| Естественность | 0.30 | Log-prob под моделью |
| Произносимость | 0.20 | CV-паттерн (согласная-гласная) |
| Баланс гласных | 0.10 | Оптимум 40% гласных |
| Длина | 0.10 | Оптимум 4-7 символов |
| Kill Feed Test | 0.10 | Буквы A-M в начале |
| Открытый финал | 0.10 | Окончание на гласную |
| Уникальность | 0.10 | Отличие от корпуса |

Плюс штрафы за мусор: 4+ согласных подряд, мёртвые кластеры, много цифр.

### 3. Проверка занятости

Через DuckDuckGo ищется `"{ник} esports"`. Если в результатах есть
Liquipedia, HLTV, Twitch, Twitter и т.п. — ник занят. Иначе — свободен.

## Структура проекта

```
NICKNAME-FORGE/
├── core/              # ядро: константы, модели данных, утилиты
├── corpus/            # обучающие данные: 500+ ников + стоп-слова
├── generators/        # N-gram модель + Ollama (заготовка)
├── scoring/           # фонетика, правила платформ, скорер
├── checkers/          # проверка занятости (DuckDuckGo, Minecraft, Roblox)
├── interfaces/        # CLI, Telegram, Web (заготовки)
├── tests/             # тесты
├── main.py            # точка входа
├── demo.py            # демонстрация
└── create_structure.py # скрипт создания структуры
```
